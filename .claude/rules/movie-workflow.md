# Movie experiment workflow

Правила применяются при работе в `scripts/movie_experiment/` — AI-пайплайн короткометражки "Пиньята".

## Когда запускать генерации

1. **Не запускать новую генерацию пока старая в процессе** — Evolink списывает кредиты за каждую, если старая зависла и я запускаю новую, жгём двойной счёт.
2. **Не запускать ничего без явного "ок"/"давай"** — когда пользователь задаёт вопрос, отвечать, а не действовать. Вопрос не равен команде.

## Качество и итерации

3. **Итерации на 480p** — дешёво, проверка промпта, композиции, таймингов.
4. **Финал на 720p** — дефолт для утверждённых кадров.
5. **1080p только для особых сцен** — когда резкость критична (крупный план, финальный мастер).

## Рефы

6. **Проверять реф перед использованием**: правильная версия (путь), нужный аспект (16:9 обычно), ч/б если сцена ч/б. Картинка могла быть обновлена пользователем — **смотреть фактический файл, не из памяти**.
7. **Консистентность персонажа** — передавать `char_bandit_front_bw.jpg` как @Image2 character reference для одежды/телосложения. Если сцена ч/б, реф тоже должен быть ч/б.
8. **При кадре со спины персонажа** реф спереди всё равно помогает модели (одежда, сборка), не мешает.

## Промпты

9. **Для Seedance всегда перечитывать `scripts/movie_experiment/docs/seedance_prompting_guide.md`** — не по памяти. 6-step formula, timecode segmentation для >5с, одна команда камеры, физические детали действий.
10. **Не микроменеджить свет/тени** — сказал "коллаж, встрой естественно" и пусть модель сама решит. Описывать направление/форму тени — получаются дикие кадры.
11. **Не додумывать за модель** ("лицо выйдет неверным", "пыль улетит") без теста. Это паттерн, на который пользователь ловит снова и снова.

## Картинки — какой провайдер

12. **Gemini 3 Pro Image (через Google API)** — лучший для точечных правок на существующем кадре ("добавь биту", "замени мяч на кубок"). `--provider google --size 2K`.
13. **Flux 2 (через OpenRouter)** — новые кадры от сцены/описания, композиция с нуля. flux.2-pro / flux.2-max.
14. **Seedream 5.0 Lite (через Evolink)** — ByteDance, тянет edge-контент (висящий труп), multi-ref до 14 картинок. Квест с SSL из РФ, через прокси.

## Видео

15. **Seedance 2.0 reference-to-video** — единственный режим в `seedance_video.py` (мы убрали image-to-video). Принимает image + video + audio рефы.
16. **Reference-to-video блокирует фотореалистичные face refs** — content_policy_violation на голые портреты. Для face swap — локально через facefusion.
17. **facefusion headless-run** — `inswapper_128` + `gfpgan_1.4` + `--face-selector-mode one` обязательно. Без `one` он в reference mode и не свапает.
18. **Аудио-рефы в промпте** — `@Audio1 is the first line spoken by the man`. Seedance делает lip-sync, если аспект shot близко к persona.

## Поведение

19. **Смотреть картинку перед предложением** — не рассуждать из памяти. Пользователь ловит на этом регулярно.
20. **При ошибках API (SSL/timeout) на poll** — задача на сервере обычно доделывается, опросить напрямую task_id через прокси и скачать результат. Не запускать заново.
21. **Кредиты Evolink показываются в error 402** — если кончились, сказать пользователю и ждать пополнения, не пытаться повторять.
