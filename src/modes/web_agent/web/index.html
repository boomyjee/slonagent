🐘 SlonAgent Web Agent

Основной способ — Chrome-расширение со side panel. Чат живёт в боковой панели браузера и переживает навигацию между страницами, так что агент может прокликивать целые сценарии без перезагрузки виджета.

Установка расширения

  1. Возьмите папку src/modes/web_agent/extension/ из репозитория slonagent (склонируйте репо или скачайте её содержимое любым способом).
  2. Откройте chrome://extensions, включите Developer mode в правом верхнем углу.
  3. Нажмите Load unpacked и укажите ту самую папку extension/.
  4. В панели инструментов появится иконка Slonagent — кликните по ней, откроется side panel.
